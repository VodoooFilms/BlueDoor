# Revisión de la versión local — 17 de octubre de 2026

Revisión de los cambios de seguridad y rendimiento pendientes de commit; no constituye una nueva auditoría exhaustiva ni una certificación de seguridad.

- Importación de documentos: el drop nativo autoriza la ruta canónica y el IPC consume la autorización una sola vez. El diálogo nativo sigue siendo la alternativa.
- Helpers OCR/layout: se rechazan rutas relativas antes de invocar el proceso.
- Modelos: `check_model_exists` limita las consultas al catálogo y al directorio canónico de modelos. Es una comprobación de presencia/tamaño; la verificación criptográfica sigue en la carga/descarga.
- Editor: snapshots estructurales, sincronización de regla al soltar y lectura de extensión mediante rAF.
- Se corrigió un detalle del nuevo fast path: la expresión regular no consumía el espacio que precede a cada atributo, por lo que el HTML con formato siempre reconstruía el DOM. Se añadió una regresión que verifica el fast path y la eliminación de scripts/event handlers.

Validación: `pnpm typecheck`, `pnpm build`, `pnpm check:native`, `pnpm test:native` (104 aprobadas, 15 omitidas por fixtures/modelos), y suites UI general, workspace y layout. El test de PCM tuvo un fallo intermitente de muestras/tiempo durante una ejecución; se repitió la suite para verificar el resultado.

El repositorio de publicación es el privado `VodoooFilms/belegal`. La nueva marca Local Legal se desarrollará en una copia independiente. Esta revisión no recompila ni reemplaza la aplicación instalada.
