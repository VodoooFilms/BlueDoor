# BlueDoor - chequeo final de la app

Fecha: 17 de octubre de 2026. Base revisada: `7c5a7ddd005a07304d34149bf4ac07c404b74642`, más las correcciones descritas abajo. Producto 0.4.0; build macOS 0.4.1; Apple Silicon. Revisión interna con inspección de código, pruebas automatizadas y comprobación del paquete instalado. No es un pentest independiente ni una certificación.

## Resultado

Los flujos verificados pasan sus pruebas. No se detectaron regresiones en importación, edición, mapa privado, exportación revisada, audio, modelos o distribución del espacio en la interfaz. Se corrigieron ocho avisos npm y mensajes con la marca anterior. La aplicación sirve para continuar la revisión local; todavía no corresponde declarar esta compilación lista para distribución comercial.

## Correcciones realizadas

- Dependencias indirectas: `devalue` 5.9.2 -> 5.9.4 y `source-map-js` 1.2.1 -> 1.2.2. El análisis inicial de todo npm reportaba cinco avisos altos, dos moderados y uno bajo; el análisis posterior, incluyendo herramientas de desarrollo, reporta cero avisos conocidos. Solo cambió el lockfile, sin añadir dependencias directas.
- Cuatro errores nativos de carga de IA indicaban una marca anterior. Ahora indican BlueDoor.
- `PRIVACY.md`: se eliminó una garantía excesiva de saneado completo y se documentó la navegación opcional a ChatGPT, la carga manual externa y los límites de detección.

Estas correcciones quedan en el proyecto. No se reinstaló ni reinició la app: contiene un documento abierto del usuario. No se incluyó su contenido en los artefactos de auditoría.

## Superficie revisada

| Área | Evidencia y límite |
| --- | --- |
| Tauri y CSP | Scripts propios, conexiones del renderer limitadas a la app/IPC, sin frames, objetos ni formularios externos. Estilos inline siguen permitidos para el editor. Capacidades de ventana limitadas; no se otorga al renderer una API general de shell o archivos. La app nativa no usa App Sandbox. |
| 40 comandos IPC registrados | Se inspeccionaron el registro y los límites relevantes de importación, audio, exportación, modelos y navegador. No se afirma fuzzing exhaustivo de cada argumento. |
| Importación | Las rutas de documentos por drop nativo se canonizan, autorizan y consumen una vez. Se mantiene el diálogo nativo y el rechazo de rutas inventadas; las pruebas cubren el consumo único. |
| Helpers | Guardia de rutas absolutas antes de spawn. El decoder empaquetado permite únicamente el protocolo file. Esto no constituye una garantía contra vulnerabilidades desconocidas de los parsers. |
| Modelos | Catálogo fijo, tamaños y SHA-256; integridad en descarga/carga. `check_model_exists` restringe a catálogo y directorio canónico: su comprobación rápida de presencia no sustituye el hash. |
| HTML enriquecido | Lista de etiquetas, atributos y estilos permitidos; scripts y eventos eliminados. Prueba de fast path y fallback de HTML hostil correcta. |
| Exportación privada | Validación nativa de sesión, revisión y contenido exacto; rechazo de mapa vacío, contenido alterado, revisiones obsoletas y ciertos residuos. Los casos negativos pasan. No garantiza que el modelo haya encontrado toda la información sensible. |
| Errores y layout | Pruebas de micrófono ausente, denegado y ocupado; formatos no válidos y audio ilegible; mensajes largos y progreso sin mover los controles. Fondo azul oscuro y notificaciones a la izquierda. |
| ChatGPT | El comando nativo abre únicamente `https://chatgpt.com/`, sin argumentos de documento, texto, título o ruta. No adjunta ni sube el PDF. El test de UI comprueba el contrato y el fallo del abridor; no automatiza una sesión autenticada real de ChatGPT. |
| Datos locales | Historial en JSON local sin cifrado propio. Documentos y mapa privados en memoria de sesión; swap/dumps y seguridad del equipo siguen siendo límites. Sin telemetría configurada en el código inspeccionado. |
| Instalación | Se inspeccionó `/Applications/BlueDoor.app`, en ejecución con una sesión abierta. No se alteró esa sesión. No se volvió a realizar una instalación limpia en otro Mac. |

## Pendientes materiales

### 1. Evidencia de licencias de distribución

El gate de ingeniería sigue en FAIL por falta de textos de licencia de cinco paquetes Rust: `adobe-cmap-parser@0.4.1`, `llama-cpp-2@0.1.156`, `llama-cpp-sys-2@0.1.156`, `pdf-extract@0.7.12` y `type1-encoding-parser@0.1.1`. No significa que estén prohibidos: el paquete de atribuciones no demuestra todavía todas las obligaciones. Incorporar textos verificables de upstream, regenerar inventario y volver a ejecutar el gate antes de distribuir comercialmente.

### 2. Firma y aceptación macOS

La firma ad hoc verifica la integridad local, pero no identifica a un desarrollador para distribución. Gatekeeper rechaza el paquete actual. Faltan Developer ID, notarización, stapling y comprobación de descarga/primer arranque en un Mac limpio. No se desactivaron protecciones del sistema.

### 3. Detección con revisión humana

La evaluación histórica en `docs/PRIVACY_EVALUATION.md` registra eliminación de 195/282 valores anotados (69,1 %) en 32 documentos OpenPII y 67/109 (61,5 %) en 20 documentos financieros Gretel. Son muestras pequeñas de la línea base del 3 de octubre, no resultados nuevos ni una medición representativa del modelo actualmente seleccionado. Hay omisiones documentadas y no consta aquí una validación posterior que las resuelva. La revisión manual sigue siendo necesaria; no prometer anonimato ni envío automático seguro.

### 4. Alcance de dependencias

El análisis de avisos ejecutado cubre npm. No se ejecutó un nuevo barrido RustSec/Cargo Audit; Clippy, tests e inventario de licencias no lo sustituyen. Tampoco se realizó una captura de tráfico del proceso nativo ni una revisión de vulnerabilidades independiente de FFmpeg, OCR y librerías de inferencia. Este chequeo no permite declarar ausencia total de vulnerabilidades.
